# Simple Calculator

A modern, functional calculator application built with React, TypeScript, and Three.js for rendering elements. 

## Features
- **Clean UI**: A sleek, minimalistic interface powered by Tailwind CSS.
- **Accurate Physics/Graphics**: Uses Three.js for interactive aesthetic elements (if integrated).
- **Smooth Animations**: Uses Framer Motion for responsive UI transitions.

## Tech Stack
- Frontend: React + TypeScript
- Build Tool: Vite
- Styling: Tailwind CSS
- 3D/Effects: Three.js
- Animations: Framer Motion

## Installation

1. Install dependencies
```bash
npm install
```

2. Start the development server
```bash
npm run dev
```

3. Build for production
```bash
npm run build
```
